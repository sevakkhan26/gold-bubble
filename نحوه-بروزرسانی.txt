نحوه‌ی بروزرسانی سایت — gold-bubble v2.1.0
═══════════════════════════════════════════

این بسته شامل نسخه‌ی بروزرسانی‌شده‌ی کامل پروژه است (v2.1.0).

─ راه اول (توصیه‌شده): دیپلوی خودکار از طریق گیت‌هاب ─────────────────
۱) این پوشه را روی سیستم خود (لپ‌تاپ/کامپیوتر توسعه) اکسترکت کنید
   و محتویات آن را جایگزین پوشه‌ی gold-bubble خود کنید.
۲) اسکریپت بروزرسانی را اجرا کنید:
      مک/لینوکس:  bash update.sh "بروزرسانی به v2.1.0"
      ویندوز:     update.bat "بروزرسانی به v2.1.0"
   (کامیت می‌شود + به گیت‌هاب پوش می‌دهد؛ در صورت نبود origin،
   نام کاربری و توکن را می‌پرسد)
۳) پولر خودکار سرور LAN تا ~۳۰ ثانیه بعد تغییر را می‌بیند و دیپلوی می‌کند.
   برای دیپلوی فوری (بدون انتظار):
      LAN_WEBHOOK="http://192.168.50.128:9000/hooks/update-gold-bubble?token=..." bash update.sh

─ راه دوم: دیپلوی دستی روی خود سرور ─────────────────────────────────
فایل‌ها را روی سرور جایگزین پوشه‌ی
   /home/server/docker-projects/gold-bubble/
کنید (فقط محتویات؛ پوشه‌ی .git هم اگر هست دست نزنید) و اجرا کنید:
   bash deploy-server.sh
(= git pull --ff-only && docker compose build && docker compose up -d)

─ فعال‌سازی امکانات امنیتی جدید (اختیاری ولی توصیه‌شده) ─────────────
در فایل .env روی سرور اضافه کنید:
   API_TOKEN=یک_رمز_دلخواه
   TRADE_ALLOWED_DOMAINS=api.wallex.ir,api.nobitex.ir
سپس دوباره دیپلوی کنید. توکن را می‌توانید از صفحه‌ی «تنظیمات» سایت هم
وارد کنید (فقط در همان مرورگر ذخیره می‌شود).
