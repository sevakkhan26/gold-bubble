═══ راه‌اندازی سایت روی کامپیوتر خودتان ═══

【ویندوز — روش اصلی (start-site.bat)】
  این بسته پایتون و همه‌چیز را همراه خود دارد؛ حتی نیازی نیست
  پایتون روی سیستم شما نصب باشد. سرور هم بدون نصب هیچ کتابخانه‌ای
  اجرا می‌شود.
  ۱) زیپ را اکسترکت کنید: کليک راست روی فایل زیپ → Extract All
     (اگر ویندوز درباره‌ی پایتونِ داخل بسته سوال کرد: More info →
      Run anyway — یعنی «اجرا کن»)
  ۲) وارد پوشه‌ی gold-bubble شوید
  ۳) روی  start-site.bat  دوبار کلیک کنید
  ۴) چند ثانیه بعد می‌نویسد «سایت آماده است» و مرورگر خودکار باز
     می‌شود:  http://localhost:8787
  ۵) برای خاموشی: پنجره‌ی «Gold Market Site Server» را ببندید
  اگر پیام «سایت بالا نیامد» دیدید: خودکار فایل lite.log در Notepad
  باز می‌شود — از آن اسکرین‌شات بگیرید و برای پشتیبان بفرستید.
  نکته: هر بار که این فایل را اجرا کنید، اگر نسخه‌ی قدیمی‌تری از
  سرور در حال اجرا باشد، خودش آن را متوقف و نسخه‌ی جدید را بالا
  می‌آورد (لازم نیست چیزی را دستی ببندید).

  (اگر قبلاً با start.bat یا start-lite.bat آشنا هستید، فرقی ندارد؛
   همه به همین کار می‌رسند.)

【ویندوز — نسخه‌ی کامل (کیف پول + سفارش)】
  روی start.bat دوبار کلیک کنید (بار اول وابستگی‌ها را نصب می‌کند).
  اگر نصب کتابخانه‌ها خطا داد، از start-site.bat استفاده کنید.

【مک / لینوکس】
  ۱) پوشه را اکسترکت کنید و ترمینال را در آن باز کنید:
        cd gold-bubble
        python3 lite/server.py        (سبک، بدون نصب چیزی)
        یا
        bash start.sh                  (نسخه‌ی کامل)
  ۲) مرورگر خودکار باز می‌شود. (Ctrl+C برای خاموشی)

【با داکر (روی هر سیستمی که داکر دارد)】
        docker compose up -d --build
        مرورگر: http://localhost:8787

═══ نصب پایتون (فقط در صورت نیاز) ═══
  install-python.bat این کار را خودش می‌کند؛ نیازی به کار اضافه نیست.
  اگر دانلود کند بود: نوار پیشرفت را می‌بینید — یعنی در حال کار است،
  صبر کنید. اگر هر ۳ منبع ناموفق بود، پیام می‌دهد و آدرس دستی می‌دهد.

═══ اگر نسخه‌ی سایت آپدیت نمی‌شود ═══
  رایج‌ترین دلیل: سرور قدیمی هنوز در حال اجراست و پنجره‌ی آن بسته
  نشده است؛ start-site.bat هم قبلاً فقط مرورگر را باز می‌کرد. حالا:
  ۱) مطمئن شوید فایل‌های جدید را دارید — نسخه‌ی بسته باید جدیدترین
     باشد (نام زیپ: gold-bubble-update-v2.2.4.zip) و پوشه‌ی قدیمی را
     کاملاً جایگزین کرده باشید (یا فایل‌های جدید را روی همان پوشه
     کپی کنید — مخصوصاً lite/server.py و start-site.bat).
  ۲) پنجره‌ی «Gold Market Site Server» قدیمی را ببندید (اگر باز است).
     اگر پنجره‌ای باز نیست ولی باز سرور قدیمی اجراست: Task Manager
     (Ctrl+Shift+Esc) → تب Details → روی python.exe کلیک راست → End task.
  ۳) دوباره روی start-site.bat کلیک کنید. حالا خودش بررسی می‌کند:
     - اگر نسخه‌ی در حال اجرا قدیمی باشد، آن را متوقف و نسخه‌ی جدید
       را بالا می‌آورد (در پنجره می‌نویسد «نسخه‌ی قدیمی... متوقف می‌شود»).
     - اگر همان آخرین نسخه باشد، فقط مرورگر را باز می‌کند.
  ۴) برای اطمینان، در مرورگر این آدرس را باز کنید:
        http://localhost:8787/api/version
     باید نمایش دهد:  {"version": "2.2.4-lite", ...}
  ۵) رفرش سخت مرورگر:  Ctrl+F5  (یا پنجره‌ی ناشناس/Incognito باز کنید)
  ۶) اگر هنوز قدیمی می‌بینید: آدرس  http://localhost:8787/api/version
     را در مرورگر چک کنید — اگر نسخه‌ی جدید را نشان داد، فقط یک
     Ctrl+F5 بزنید؛ اگر قدیمی را نشان داد، از Task Manager همه‌ی
     python را ببندید و دوباره start-site.bat.

═══ اگر صفحه بالا آمد ولی قیمت خالی بود ═══
  این یعنی سرویس‌های قیمت از اینترنتِ سیستم شما قابل دسترسی نیستند.
  به ترتیب این‌ها را امتحان کنید:
  ۱) فایروال ویندوز / آنتی‌ویروس: وقتی اول بار پایتون را اجرا کردید،
     پیام «Allow python to communicate» آمده؟ اگر رد (Cancel) کرده‌اید:
     Windows Security → Firewall & network protection → Allow an app
     → python را Allow کنید. (یا آنتی‌ویروس را موقتاً خاموش کنید)
  ۲) چند دقیقه صبر کنید — اولین دریافت قیمت تا ۱-۲ دقیقه طول می‌کشد
     (شبکه‌ی عادی: ۱۰-۲۰ ثانیه).
  ۳) توی مرورگر این آدرس را باز کنید تا ببینید کدام منبع خطا دارد:
        http://localhost:8787/api/debug
     یا از منوی سایت، صفحه‌ی «منابع API» را ببینید (هر منبع OK/ERR دارد).
     از آن صفحه اسکرین‌شات بگیرید و برای پشتیبان بفرستید.
  ۴) اتصال اینترنت را با باز کردن  https://api.gold-api.com/price/XAU
     در مرورگر تست کنید (باید یک عدد بدهد).
  ۵) نسخه‌ی ۲.۲.۲ به‌بعد آخرین قیمت‌های موفق را در فایل lite_last.json
     ذخیره می‌کند؛ بعد از هر ریاستارت، بلافاصله همان قیمت‌ها (با نشان
     «تازه نبودن») نمایش داده می‌شوند تا دریافت تازه موفق شود.

═══ اگر بالا نیامد — عیب‌یابی سریع ═══
  ۱) روی diagnose.bat دوبار کلیک کنید و از پنجره‌ی آن اسکرین‌شات بگیرید
     و برای پشتیبان بفرستید — همه‌چیز را نشان می‌دهد.
  ۲) رایج‌ترین دلایل:
     • اجرا از داخل خود زیپ → اول Extract All کنید.
     • پیام «پورت 8787 اشغال است» → برنامه‌ی دیگری روی همین پورت است؛
       آن را ببندید.
     • نصب پکیج‌ها خطا داد (اتصال اینترنت قطع/کند) → اینترنت را بررسی
       و دوباره start.bat را اجرا کنید.
     • پنجره‌ی «Gold Market Live Server» را باز کنید و متن آخر آن را ببینید.
  ۳) اگر صفحه باز شد ولی قیمت خالی بود: بخش «اگر صفحه بالا آمد ولی قیمت
     خالی بود» بالاتر را ببینید (فایروال مهم‌ترین دلیل است).

═══ چرا قبلاً گیر می‌کرد؟ ═══
  ۱) دانلود قبلی بی‌صدا بود (بدون نوار پیشرفت) و فقط یک منبع داشت —
     روی اینترنت کند یعنی چند دقیقه پنجره‌ی خالی، شبیه «گیر کردن».
     حالا نوار پیشرفت زنده + ۳ منبع دانلود دارد.
  ۲) فایل‌ها به تنهایی کافی نبودند: باید وابستگی‌ها نصب می‌شد — حالا
     خودکار است.
  ۳) برنامه موقع بالا آمدن منتظر قیمت‌ها می‌ماند — حالا سایت فوراً بالا
     می‌آید و قیمت‌ها در چند ثانیه پر می‌شوند.
  ۴) دوبار کلیک روی public/index.html کافی نیست — سایت حتماً باید
     از طریق start.bat / install-python.bat (یا داکر) اجرا شود.
